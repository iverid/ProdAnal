# ProdAnal

[English version](README.md)

Командный проект (трек А) по дисциплине «Продуктовая аналитика», МГТУ им. Н.Э. Баумана, осень 2026. Часть 1 (PA-S1, «Начало работы»).

## Задача

Первая часть проекта фиксирует, что мы делаем, на каких данных и как это будет измеряться. Результат — один ноутбук `project.ipynb`, который выполняется от начала до конца и служит основой для следующих этапов проекта.

Мы анализируем Olist, бразильский e-commerce-сервис, как двустороннюю платформу (покупатели и продавцы). В ноутбуке девять разделов:

1. Продукт: что делаем, для кого, какую проблему решает, гипотезы ценности, бизнес-модель.
2. Данные: источники, лицензии, объём, период, ограничения; проверка качества (пропуски, дубли, выбросы, тестовые пользователи, границы времени); почему датасеты подходят.
3. Определения: активный пользователь, конверсия, удержание, когорта, правило оттока.
4. Метрики: North Star, две диагностические и одна риск-метрика (пирамида метрик).
5. Трекинг: таблица событий с триггером, параметрами, метрикой, этапом пути и полем датасета.
6. Первые расчёты: когортный retention, возврат за 30/60/90/180 дней, LTV/CAC продавцов, DAU/WAU/MAU.
7. Этический чек-лист.
8. Критерии успеха: целевые значения ключевых метрик и способ проверки.
9. Репозиторий.

## Как запустить

Рекомендуется Python 3.10 или новее.

1. Склонируйте репозиторий и перейдите в его корень:
   ```bash
   git clone https://github.com/iverid/ProdAnal.git
   cd ProdAnal
   ```
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   source .venv/bin/activate        # Windows: .venv\Scripts\activate
   ```
3. Установите зависимости с зафиксированными версиями:
   ```bash
   pip install -r requirements.txt
   ```
4. Убедитесь, что обе папки с данными лежат в `data/` (см. раздел «Данные»).
5. Запустите Jupyter **из корня репозитория**, откройте `project.ipynb` и выберите *Kernel → Restart & Run All*. Ноутбук читает данные по относительному пути `data/` и останавливается с сообщением, если запущен из другой папки. Абсолютных путей нет.

## Что получилось

- Новые покупатели в основном покупают один раз: в течение 90 дней возвращаются 1,30%, в течение 180 дней — 1,99% (20 месячных когорт, 93 094 новых покупателя). Доля покупателей хотя бы с двумя доставленными заказами — 3,0%, с покупками в две разные даты — 2,15%.
- Продавцы: 43,2% из 667 продавцов с полным 90-дневным наблюдением начинают продавать в течение 90 дней после сделки. При допущении о комиссии 15% LTV90 сделки — 74 BRL; максимальный CAC при LTV/CAC = 3 — 25 BRL. Заявки из соцсетей конвертируются хуже всего (5,6% против 11,8–12,3% у поиска).
- MAU в 2018 году держится на уровне 6–7 тыс. покупателей, 97–99% из них новые; DAU/MAU около 3%.
- Критерии успеха (раздел 8): +10% к числу успешных сделок в месяц (North Star), не менее 1,8% повторных покупок за 90 дней, не менее 50% активации продавцов за 90 дней и доля отменённых заказов не более чем на 0,5 п.п. выше базы.
